docs/21 §1：「引擎的**一切**都在 `schema.yaml`（IDL）里声明一次」；§5「目标态：runtime 只提供极少原语，
其余全部声明式」；§6.3「同一 `api_list` 再生成 MCP 工具」。

| DSL 段 | 声明内容 | 生成产物 | 编译目标 | 状态 |

| `module_abi` | **模块 C ABI**（7 个模块：vfs/asset/nav/physics/platform/input/script） | `abi/<module>.h` + `MQ_<MOD>_ABI_VERSION/_IFACE_NAME` | 各模块 | 🟡 **本轮迁移 7 个**（余 13 个：control/obs/watcher/handle/module/reflect/persist×2/image/net/math/api/runtime） |

去手写成果：runtime 内 `mq_control_register` **由 24 处降为 0**（改调用生成的注册表）；
事件路由手写 switch **删除**（改 `mq_event_dispatch`）；`on_start`/`update` 也走生成派发；
四个模块的公开 C 头**手写声明降为 shim**（`#include "abi/<mod>.h"`）。

ABI 安全验证（迁移不得改 ABI）：
- 签名/枚举/宏：与 git 基线逐条比对 → 原声明被生成物完全覆盖且等价；
- 布局：编译器实测 **48 项 sizeof/alignof/字段偏移与改动前逐位一致**；
- 新增静态断言守卫（asset/nav/physics 测试内）→ DSL 漂移即编译失败；
- 过程捕获 2 处真实 ABI 错误（nav `allow_diagonal` 应为 `uint8_t`；缺 `MQ_NAV_ERR_NOMEM`、`CAPACITY` 码值应为 6）。

仍手写的公开接口（按同一范式迁移，工具 `tools/hdr2abi.py` 已就绪）：`control`/`obs`/`watcher`/`handle`/
`module`/`reflect`/`persist`(×2)/`image`/`net`/`math`/`api`/`runtime`(`mq_host`/`mq_runtime`)。

## 0. 一句话结论

**机制类契约（声明+生成、C ABI、确定性、只读渲染方向）大部分符合且可验证；
覆盖面类契约（存储模型、生命周期、控制面 domain、3D/pass/骨骼、组件语义规模）大面积未达标。**
本轮已修 13 项违背中的 9 项；余 4 项与未实现项列于 §4/§5。

## 6. 最贴合设计的部分（可作标杆）

1. **声明+生成主线**：`schema.yaml` 单一真相 → 7 产出（类型/描述符/JSON schema/API 头/绑定/接口 vtable）；
   runtime 内 `mq_script_register` **0** 处（审计独立复核）；MANUAL 头生效（`math.saturate` 内联实现）。
2. **确定性内核**：固定步长、引擎 RNG、id 升序迭代、逐帧校验和、快照/回滚保真（`anim_e2e` 快照→前进→回滚→前进 == 直接前进）。
3. **AI 可驱动面**：`ai_workflow_e2e` 跑通 docs/11 §5 动作序列；崩溃→重放闭环（本轮补上信号路径）。
4. **插件边界**：DSL 生成 C vtable + `dlopen` + ABI 版本/结构大小校验；`-fvisibility=hidden` 后仍正确导出。
