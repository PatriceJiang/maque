# M3 · 实体与组件（世界模型）

> 上游：`docs/12`（场景/世界）、`docs/17`（组件）、`docs/20`（运行时与资源模型）。
> 目标：引擎提供**实体 + 组件**世界；**渲染从组件提取**（只读）；脚本操作组件——游戏仍是资源。

## 1. 目标

- 引擎维护**实体表**（`maque::handle`）与**组件**（transform + sprite）。
- 每帧由**渲染层从组件提取**绘制项并渲染（docs/12：渲染是只读消费方）。
- 脚本只操作**组件**（`entity_spawn / entity_set_pos / entity_destroy`），不直接绘制。
- 保留"引擎即浏览器，游戏即资源"（docs/20）：`mq_run_scene` 不变，游戏在 `.js`。

## 2. 产出

| 组件 | 说明 |
|------|------|
| 运行时实体世界 | `Runtime` 持有 `mq_handle_table`（`Entity{ transform + sprite }`） |
| 组件提取渲染 | 帧内遍历实体，`has_sprite` → 生成 DrawList → WebGPU（y 翻转） |
| 宿主 API 扩展 | `entity_spawn / entity_set_pos / entity_x / entity_y / entity_count / entity_destroy` |
| `scenes/ball.js` | 改为**实体/组件驱动**：spawn 实体 → 更新 transform → 销毁 |

## 3. 数据流（本切片）

```
脚本: entity_spawn/set_pos/destroy  ──▶  实体表(组件)
                                            │  (帧内, 只读)
引擎: 提取 sprite 组件 ──▶ DrawList ──▶ WebGPU ──▶ 帧
```

## 4. 验收（实测）

```
runtime: scene 'scenes/ball.scn' script='ball.js' 320x240 seed=12345
[game] ball: spawn entity id=0
[game] ball: destroy entity id=0        # 静止 5s 后由脚本销毁
runtime: exited after 436 frames (quit=1)
```
- 逐帧像素分析：帧 30/150/300 均有球（非背景 ≈ 208 = π·8²）；销毁后循环随 `quit` 结束。
- ctest：`player_run` 通过（8/8）。

## 5. 遗留 / 下一步（M3b）

- **场景树直接来自资源**：当前实体由脚本创建；下一步让 `.scn` 描述**节点/实体树**
  （`scn.Scene.entities: Entity[]`），需为反射补 **动态数组（`T[]`）反序列化**（codegen 生成容器算子）。
- **组件化落库**：把 `Entity` 拆成 `Transform2D` + `Sprite` 等**反射组件类型**（docs/17），
  支持多组件组合与按类型查询。
- **节点树 ⇄ ECS 双视图**（docs/12）：编辑期节点树 → bake → ECS。
