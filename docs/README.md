## 三条主线（速览）

1. **AI 可用性五指标**（[00 §4](00-设计哲学与约束.md)）：
   A1 可自省 · A2 可观测 · A3 可复现 · A4 可操作 · A5 快迭代。
2. **数据即真相**：反射（[06](06-反射与代码生成.md)）是中枢，序列化（[08](08-资源持久化与资产管线.md)）／脚本绑定（[14](14-脚本.md)）／场景（[12](12-场景与世界.md)）／AI 全部由它派生。
3. **架构 ≈ 浏览器同构体**（[16](16-与浏览器架构对照.md)）：`DOM⇄节点树`、`CDP⇄控制平面`、`Web Worker⇄worker/job`。

## 关键架构决策（ADR）

详见 [00 §7](00-设计哲学与约束.md)。摘要：插件化 `.so`+C ABI（0013）、零全局状态多实例（0014）、VFS（0015）、
WASM 一等平台（0016）、反射中枢（0001/0011）、开发期文本优先（0021）、结构化可观测（0022）、
快照回放（0023）、CDP 式控制平面（0024）、WebGPU+T1 pass 层（0025）、反射生成绑定+帧边界 GC（0026）、
世界层 ECS 权威（0027）。

## 开放问题（Open Decisions）

**目前已全部收敛。** 结论：

| ID | 结论 | 决策 |
|----|------|------|
| OD-1 | 控制平面 = JSON-RPC 对齐 CDP + MCP 包装 | ADR-0024 |
| OD-2 | 双视图（节点树 → bake → ECS） | ADR-0003 |
| OD-3 | 嵌入式**不降级**，限定有 Vulkan/Metal/D3D12 的目标 | ADR-0029 |
| OD-4 | 跨 `.so` 仅 C ABI + 句柄 + 分配者释放 | ADR-0013 |
| OD-5 | quickjs 主 + refcount；cycle GC 仅帧边界 | ADR-0026 |
| OD-6 | persistence = 序列化中枢 | ADR-0011 |
| OD-7 | C++23 | ADR-0012 |
| OD-8 | WASM/浏览器为一等目标平台 | ADR-0016 |
| OD-9 | 远程资产 = 内容哈希校验 + 能力沙箱（暂不签名） | ADR-0030 |
| OD-10 | 物理集成 Rapier（Rust，C ABI FFI） | ADR-0028 |
| OD-11 | 维持 T1 pass 层，T2 按硬指标再评估 | 见文档 13 |
