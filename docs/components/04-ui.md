# 04 · 内置组件设计 — UI

> 上游：`17`（组件约定 §2/§3）、`12 §5`（UI 为独立渲染层）、`13 §4`（UI 独立 Render Graph 分支）、`06`（反射/attrs）、`10`（确定性）。
> 本文设计 5 个 UI 组件：**Control · Container · TextLabel · Image · Button**。

## 0. UI 总纲（5 个组件共享）

1. **UI 挂在节点树上**：与 2D/3D 一样是节点子树；"是不是 UI" = 挂了 `Control`（或其后继 UI 组件）。
2. **UI 是独立渲染层**：由根级 `layer / viewport` 划分，UI 层有**自己的坐标系（像素/锚点）与独立相机**，
   对应 `13 §4` 的独立 Render Graph 分支 → **UI 可与 3D 独立开发、独立调试**（`12 §5`）。
3. **绘制描述可序列化**：UI 只产出中性的绘制项（矩形/字形/纹理区域），渲染器**不认识**节点存储细节（`13 §1`）。
4. **坐标**：UI 为 2D 像素空间，原点在 UI 层左上，Y 向下；`Control` 是唯一持有布局字段的组件，
   `TextLabel / Image / Button` **必须与 `Control` 同挂于同一节点**（配对关系），由 `Control` 决定其外框。
5. **事件模型 = 信号**：UI 交互（点击、悬停、文本变更）以**信号**暴露，脚本按名 `connect`；
   信号描述符经反射生成（`06 §6`、`14 §2`），**禁止手写绑定**。
6. **事件是数据**：输入先落为**输入记录**（`10 §3`），UI 在模拟线程消费记录做命中测试 → 回放一致。

## Control

- **归属模块 / 上游文档**：`ui` 模块 · `17 §2` / `12 §5` / `13 §4`
- **说明**：所有 UI 元素的**布局基座**。给定"锚点 + 偏移"把元素外框定位到父矩形上，并约束
  最小/最大尺寸；`Container` 在此基础上排版子元素，`TextLabel / Image / Button` 在此基础上自绘。
  一个 UI 节点**必须有且仅有一个** `Control`。
- **依赖类型 / enum**：
  - `Anchor`（锚点预设）：`TopLeft / TopCenter / TopRight / CenterLeft / Center / CenterRight / BottomLeft / BottomCenter / BottomRight / FullRect / Custom`
  - `SizeFlag`（尺寸策略）：`ShrinkBegin / ShrinkCenter / ShrinkEnd / Expand / ExpandFill`
  - `MouseFilter`（命中过滤）：`Stop / Pass / Ignore`

- **字段表**：

| 字段 | 类型 | 默认 | attrs | 说明 |
|------|------|------|-------|------|
| `anchor_preset` | `Anchor` | `TopLeft` | `range` | 预设；写入时展开为下面的归一化锚点 |
| `anchor_min` | `Vec2` | `{0,0}` | `range:[0,1]` | 左/上锚点（相对父矩形，归一化） |
| `anchor_max` | `Vec2` | `{0,0}` | `range:[0,1]` | 右/下锚点（相对父矩形，归一化） |
| `offset_min` | `Vec2` | `{0,0}` | `unit:px` | 相对左/上锚点的像素偏移 |
| `offset_max` | `Vec2` | `{100,30}` | `unit:px` | 相对右/下锚点的像素偏移（决定尺寸） |
| `pivot` | `Vec2` | `{0,0}` | `range:[0,1]` | 旋转/缩放中心（归一化于自身矩形） |
| `min_size` | `Vec2` | `{0,0}` | `unit:px` | 布局下限；`{0,0}`=仅由内容决定 |
| `max_size` | `Vec2` | `{0,0}` | `unit:px` | 布局上限；`{0,0}`=不限 |
| `size_flags_h` | `SizeFlag` | `ShrinkBegin` | — | 父为 `Container` 时水平尺寸策略 |
| `size_flags_v` | `SizeFlag` | `ShrinkBegin` | — | 垂直尺寸策略 |
| `visible` | `bool` | `true` | — | 为假则不绘制且不参与命中测试 |
| `mouse_filter` | `MouseFilter` | `Stop` | — | 是否截获指针事件（决定事件穿透） |
| `z_index` | `int32` | `0` | `range` | 层内绘制顺序（同级按此再按声明序） |
| `rect` | `Vec4` | `{0,0,0,0}` | `transient` | 解算后的外框 `{x,y,w,h}`（像素，运行时派生） |
| `scale` | `Vec2` | `{1,1}` | — | 自身缩放（围绕 `pivot`） |
| `rotation` | `float` | `0` | `unit:rad` | 自身旋转（围绕 `pivot`） |

- **句柄/引用**：无资产引用；父/子关系走节点树的 `entity_ref`（`12 §3`）。布局解算的**唯一输入**是
  自身字段 + 父 `Control.rect`，无隐式全局状态。
- **生命周期 / 确定性**：布局在**模拟线程**、于**固定点**（`process` 之前的 layout pass）按
  **深度优先 + 声明序**解算；`rect` 为确定性函数（树状态 + 视口尺寸），可作为 `transient` 参与快照以保证逐帧一致。
  命中测试消费**输入记录**（`10 §3`），不读设备 → 回放一致。渲染光栅化是只读消费方，不入校验和（`13 §8`）。
- **序列化**：`rect` 标 `transient`，不落盘；其余字段均序列化。`anchor_preset` 与 `anchor_min/max` 一并存盘，
  反序列化以 `anchor_min/max` 为准（preset 仅作编辑提示）。

## Container

- **归属模块 / 上游文档**：`ui` 模块 · `17 §2` / `12 §5`
- **说明**：自动排版**子 `Control`** 的布局器。与 `Control` **同挂于同一节点**（`Container` 依赖 `Control` 提供自身外框）。
  按 `mode` 决定子是横向/纵向/网格排列；子元素用各自的 `size_flags_*` 参与拉伸。用于工具栏、列表、面板。
- **依赖类型 / enum**：
  - `ContainerMode`：`Free / HBox / VBox / Grid`
  - `Align`（主轴/交叉轴对齐，共用）：`Begin / Center / End`
  - `SizeFlag`（复用 `Control`）

- **字段表**：

| 字段 | 类型 | 默认 | attrs | 说明 |
|------|------|------|-------|------|
| `mode` | `ContainerMode` | `Free` | — | `Free`=不排版（子仍按自身锚点）；其余按模式排 |
| `padding` | `Vec4` | `{0,0,0,0}` | `unit:px` | 内边距 `{左,上,右,下}` |
| `spacing` | `float` | `0` | `unit:px` | 相邻子元素间距 |
| `align_main` | `Align` | `Begin` | — | 主轴对齐（`HBox` 水平 / `VBox` 垂直） |
| `align_cross` | `Align` | `Begin` | — | 交叉轴对齐 |
| `columns` | `int32` | `1` | `range:[1,128]` | `Grid` 列数（仅 `Grid` 有效） |
| `grid_cell` | `Vec2` | `{0,0}` | `unit:px` | `Grid` 单元尺寸；`{0,0}`=按最大子元素自适应 |
| `fit_content` | `bool` | `false` | — | 为真时容器按内容收缩自身尺寸（覆盖 `offset_max` 解算） |

- **句柄/引用**：子元素经节点树子列表（`entity_ref` 声明序）遍历，**无资产引用**。
- **生命周期 / 确定性**：排版在 layout pass 内进行，顺序 = 子声明序（`12 §6`），确定；`Auto Size`/`fit_content`
  的解算为纯函数，无墙钟依赖。作为模拟线程数据参与快照。
- **序列化**：全部字段序列化；无 transient 字段（排版结果写回子 `Control.rect`，各自标各自 `transient`）。

## TextLabel

- **归属模块 / 上游文档**：`ui` 模块 · `17 §2` / `13 §4`（字形 → 绘制描述）
- **说明**：绘制一段文本。**必须与 `Control` 同挂**；`Control.rect` 为其可用包围盒，`TextLabel` 负责
  字体、字号、颜色、换行与对齐。产出的是**字形绘制项**，渲染器据文字图集批处理（`13 §5`）。
- **依赖类型 / enum**：
  - `Align`（复用 `Container`）：`Begin / Center / End`
  - `TextWrap`：`None / Word / Char / WordSmart`
  - `asset_ref<Font>`

- **字段表**：

| 字段 | 类型 | 默认 | attrs | 说明 |
|------|------|------|-------|------|
| `text` | `string` | `""` | — | 文本内容（UTF-8） |
| `font` | `asset_ref<Font>` | `null` | `ref:Font` | 字体资产；空则用 UI 主题默认字体 |
| `font_size` | `float` | `16` | `unit:px, range:[1,512]` | 字号（像素） |
| `color` | `Vec4` | `{1,1,1,1}` | — | 文字颜色（线性空间，含 alpha） |
| `align_h` | `Align` | `Begin` | — | 水平对齐 |
| `align_v` | `Align` | `Begin` | — | 垂直对齐 |
| `wrap_mode` | `TextWrap` | `None` | — | 换行策略 |
| `line_spacing` | `float` | `0` | `unit:px` | 行距附加量 |
| `outline_size` | `float` | `0` | `unit:px` | 描边宽度；`0`=无 |
| `outline_color` | `Vec4` | `{0,0,0,1}` | — | 描边颜色 |
| `uppercase` | `bool` | `false` | — | 是否转大写 |
| `text_size` | `Vec2` | `{0,0}` | `transient` | 排版后文本尺寸（像素，运行时派生） |

- **句柄/引用**：`font` 为 `asset_ref<Font>`（存句柄，序列化为稳定资产 ID/路径，`06 §3`）。
- **生命周期 / 确定性**：文本整形/换行在 layout pass 内计算，写 `text_size`。**注意**：形状/字形度量可能
  因平台 libm/字体差异而不同，故 `text_size` 标 `transient`，**默认不进入模拟校验和**；需要像素级回放一致时
  用引擎内置位图字体或规范化的字形度量表。`text` 变更在帧边界生效。
- **序列化**：`text`、`font`(句柄)、样式字段全部序列化；`text_size` transient 不落盘。

## Image

- **归属模块 / 上游文档**：`ui` 模块 · `17 §2` / `13 §5`（纹理经 VFS 加载）
- **说明**：绘制一张纹理/图集区域（图标、背景、九宫格底图）。**必须与 `Control` 同挂**；
  `Control.rect` 为目标区域，`Image` 决定纹理、染色与拉伸方式。
- **依赖类型 / enum**：
  - `StretchMode`：`Scale / KeepAspect / KeepAspectCentered / KeepAspectCovered / Tile / KeepCentered`
  - `asset_ref<Texture>`

- **字段表**：

| 字段 | 类型 | 默认 | attrs | 说明 |
|------|------|------|-------|------|
| `texture` | `asset_ref<Texture>` | `null` | `ref:Texture` | 纹理资产；空则不绘制 |
| `region` | `Vec4` | `{0,0,0,0}` | — | 图集子区域 `{x,y,w,h}`；`{0,0,0,0}`=整图 |
| `modulate` | `Vec4` | `{1,1,1,1}` | — | 相乘染色（含 alpha） |
| `stretch_mode` | `StretchMode` | `Scale` | — | 拉伸/平铺/保持比例策略 |
| `flip_h` | `bool` | `false` | — | 水平翻转 |
| `flip_v` | `bool` | `false` | — | 垂直翻转 |
| `tile_scale` | `Vec2` | `{1,1}` | — | `Tile` 模式下的平铺缩放 |
| `nine_patch_margin` | `Vec4` | `{0,0,0,0}` | `unit:px` | 九宫格边距 `{左,上,右,下}`；非零启用九宫格拉伸 |
| `texture_size` | `Vec2` | `{0,0}` | `transient` | 纹理原始尺寸（像素，运行时派生） |

- **句柄/引用**：`texture` 为 `asset_ref<Texture>`（句柄，序列化为稳定资产 ID/路径）。
- **生命周期 / 确定性**：纹理经 VFS 异步加载（`04`/`08`），**加载完成回调在帧边界**处理；未就绪时
  绘制占位/跳过。`texture_size` transient。绘制项仅由字段决定 → 不影响模拟，渲染为只读消费方。
- **序列化**：字段除 `texture_size` 外全部序列化；`texture` 以稳定 ID 存盘。

## Button

- **归属模块 / 上游文档**：`ui` 模块 · `17 §2` / `09`（信号经反射）· `14 §4`（脚本回调）
- **说明**：可交互的按钮。**必须与 `Control` 同挂**；`Button` 自持文本/图标与四态外观，处理指针命中与
  按下/悬停/禁用状态机，并发出**信号**。由 `Control.mouse_filter` 决定是否截获指针。
- **依赖类型 / enum**：
  - `ButtonState`（运行时状态）：`Normal / Hover / Pressed / Disabled`
  - `Align`（复用）；`asset_ref<Font>`、`asset_ref<Texture>`

- **字段表**：

| 字段 | 类型 | 默认 | attrs | 说明 |
|------|------|------|-------|------|
| `text` | `string` | `""` | — | 按钮文字 |
| `icon` | `asset_ref<Texture>` | `null` | `ref:Texture` | 按钮图标（可空） |
| `font` | `asset_ref<Font>` | `null` | `ref:Font` | 文字字体；空用默认主题字体 |
| `font_size` | `float` | `16` | `unit:px` | 字号 |
| `icon_align` | `Align` | `Begin` | — | 图标相对文字位置 |
| `text_color` | `Vec4` | `{1,1,1,1}` | — | 常规文字颜色 |
| `style_normal` | `asset_ref<Texture>` | `null` | `ref:Texture` | 四态底图；空则用纯色填充 |
| `style_hover` | `asset_ref<Texture>` | `null` | `ref:Texture` | 悬停态底图 |
| `style_pressed` | `asset_ref<Texture>` | `null` | `ref:Texture` | 按下态底图 |
| `style_disabled` | `asset_ref<Texture>` | `null` | `ref:Texture` | 禁用态底图 |
| `bg_color` | `Vec4` | `{0.3,0.3,0.3,1}` | — | 无底图时的底色（按状态调制） |
| `toggle_mode` | `bool` | `false` | — | 切换模式（点一下锁定 pressed） |
| `button_pressed` | `bool` | `false` | — | 逻辑按下态（`toggle_mode` 下持久） |
| `disabled` | `bool` | `false` | — | 禁用：不响应且置 `Disabled` 态 |
| `action` | `string` | `""` | — | 可选输入动作名；非空则按下等价触发该 action |
| `state` | `ButtonState` | `Normal` | `transient` | 运行时状态机输出（派生） |

- **句柄/引用 / 事件暴露（关键）**：
  - 交互以**信号**暴露（非回调名硬编码）：`pressed()`、`toggled(pressed:bool)`、`hover_changed(hover:bool)`。
  - 信号描述符由反射生成，脚本按名连接（`14 §2`）：`button.connect("pressed", on_pressed)`；
    同时兼容生命周期式回调命名 `_on_<signal>`（`14 §4`），由绑定层自动转接。
  - 信号派发在**模拟线程、固定点**（输入处理阶段），发射顺序确定。
  - 资产引用均为 `asset_ref`（句柄）。
- **生命周期 / 确定性**：指针命中测试消费**输入记录**（`10 §3`），按 UI 层命中优先级（`z_index` → 声明序 →
  深度优先）确定唯一目标；状态机是纯函数（当前态 × 输入记录 × `disabled`）。信号派发确定，
  参与回放（脚本据此改模拟状态）。`state` transient。
- **序列化**：字面与样式字段全部序列化；`state`、悬停等运行时量 transient 不落盘。`action` 以字符串存盘。

## 附：UI 信号速览

| 组件 | 信号 | 参数 | 说明 |
|------|------|------|------|
| Button | `pressed` | — | 正常按下（或 toggle 翻转） |
| Button | `toggled` | `bool` | `toggle_mode` 下状态翻转 |
| Button | `hover_changed` | `bool` | 指针进入/离开 |

> 信号名即稳定标识；脚本绑定与事件名字由反射导出（`06 §6`）。UI 事件处理整体在模拟线程、
> 消费输入记录、确定顺序派发 → 回放一致（`10 §2 D6`）；渲染层为独立只读消费方（`13 §8`）。
