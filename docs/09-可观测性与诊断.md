# 09 · 可观测性与诊断

> 上游：`00` A2、`05`（WASM 平台差异）、`06`（反射）、`07`（内存计数）、`04`（VFS）。
> 本文是 **A2 的落点**：观测数据是 AI 自主调试、CI 判定、回放重放的**原始数据源**。

## 1. 定位与原则

引擎必须暴露**结构化、机器可读**的运行信息。原则：

- **结构化**：事件/指标是**数据**，不是给人眼看的字符串（禁止裸 `printf` 作为唯一出口）。
- **低成本 / 可关闭**：热路径零格式化、零分配（延迟格式化 + 环形缓冲）。
- **确定性友好**：观测**不得改变**模拟行为（关掉日志，行为必须一致）。
- **程序可读**：一切可经控制平面查询（A4，文档 11）。

## 2. 日志（Structured Logging）

- **结构化事件**：`{ ts, level, domain, event_id, fields... }`，输出为 **JSON Lines**。
- **domain/分类**：按模块划分（`render`、`scene`、`fs`、`script`…），可分级开关。
- **sink 可插拔**：console / file / 内存环形缓冲 / 远程（经 VFS `https://`）。
- **热路径策略**：写入**预分配环形缓冲**，格式化**延迟**到后台/失速时。
- **崩溃时**：环形缓冲**落盘/上报**，得到崩溃前的事件尾部（极关键）。

## 3. 性能计数器（Metrics）

- **counter**（累加，如 draw calls、实体数）、**gauge**（瞬时，如内存水位）、**timer/scope**（耗时）。
- **帧统计**：帧时间、各系统耗时、GC/脚本耗时、IO 等待。
- **内存**：直接接文档 07 的分类计数（frame/persistent/pool/virtual）。
- **GPU**：WebGPU timestamp queries → pass 级耗时。
- **对外**：全部可**编程读取**（A4），并被控制平面暴露为指标端点。

## 4. Profiling / Tracing

- **作用域追踪**：`scope("physics")` 生成带起止的 trace 事件。
- **导出格式**：Chrome Trace / Perfetto 兼容（可直接用现成查看器）。
- **采样与帧捕获**：可对单帧做详细捕获，供 AI/人分析。
- **离线消费**：trace 落盘，AI 可解析。

## 5. 崩溃与诊断（Crash）

目标：**crash 能被精确定位并重放**（服务 A3）。

- **符号化**：`std::stacktrace`（ADR-0012）+ **DWARF/line tables**；**勿 strip**。
  - WASM：DWARF/sourcemap + JS 侧 `onerror` 栈拼接（文档 05 §8）。
- **上下文快照**：崩溃时记录 **RNG seed、帧号、输入日志、世界快照引用**（文档 10）→ 可回放。
- **产物**：minidump/coredump + 事件尾部（§2）+ 指标快照（§3）。
- **断言/契约**：debug 断言失败 → 结构化报告（含表达式、栈、上下文）。

## 6. 与确定性 / 回放的关系

- 崩溃上下文 = **回放的输入**（seed + 输入日志 + 快照）。二者必须成对接。
- 观测本身**不得引入不确定性**：关日志行为不变、计数器不影响迭代顺序（文档 07 §9）。

## 7. AI 可用性结合（A1/A2）

- AI 通过控制平面（文档 11）：**查询指标、续读日志尾部、拉取 trace、取崩溃报告**。
- 全部为**结构化数据** → AI 无需"猜文本"，可直接计算与对比。
- `mem://`/dump 让 AI 能**构造复现**并**验证修复**（关日志跑同一 seed，比对轨迹）。

## 8. 平台差异

| 平台 | 差异 |
|------|------|
| 原生 | 原生 coredump / minidump；文件 sink |
| 嵌入式 | 无文件系统 → 内存环形 + 串口/VFS 上报 |
| WASM | 无 coredump → DWARF + JS 栈；console/WebSocket sink |

## 9. 遗留风险

| 风险 | 处理 |
|------|------|
| 观测拖慢热路径 | 环形缓冲 + 延迟格式化 + 可关闭 |
| 观测改变行为（破坏回放） | 严格：关闭后行为一致，CI 加校验 |
| 崩溃信息缺失（WASM/嵌入式） | 保留 DWARF；事件尾部 + 上下文快照 |
| 日志爆炸 | domain 分级 + 采样 + 环形覆盖 |
| trace 体积 | 采样 + 单帧捕获 + 压缩（文档 08 codec） |
