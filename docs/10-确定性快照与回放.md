# 10 · 确定性、快照与回放

> 上游：`00` A3/A5、ADR-0005、`07`（内存确定性）、`09`（崩溃上下文）、`12`（生命周期）、`08`（序列化）。
> 本文是**自主调试与快迭代的基石**：crash/行为能被**精确重放**，世界可**快照/回滚**。

## 1. 目标

- **A3 可复现**：给定 `初始快照 + RNG seed + 输入日志`，模拟结果**逐帧一致**。
- **A5 快迭代**：世界可**快照 / 恢复 / 回滚**，等价于给 AI 一个 undo。
- **崩溃可重放**：文档 09 的崩溃上下文直接驱动回放。

## 2. 确定性规则（模拟层，强制）

| # | 规则 | 说明 |
|---|------|------|
| D1 | **固定步长** | 模拟以固定 dt 推进（累加器吸收渲染帧波动） |
| D2 | **引擎 RNG** | 每实例持有**带 seed 的确定性 RNG**；**禁用 `std::random`/全局 RNG** |
| D3 | **仅模拟时间** | 模拟内**禁止**读墙钟 / 真实时间，只用 sim time |
| D4 | **禁地址依赖** | 迭代/哈希按 **id / 句柄** 排序，绝不按指针（文档 07 §9） |
| D5 | **零初始化** | 无未初始化内存；序列化**按字段**而非按含 padding 的裸 `memcmp` |
| D6 | **单线程模拟** | 模拟单线程（ADR-0018）；worker 不得参与模拟状态 |
| D7 | **帧内无异步** | 模拟帧内不触发异步 IO/加载（文档 04 §6） |
| D8 | **浮点确定** | 关 `-ffast-math`；见 §6 的平台范围说明 |

> 热路径遵守 P0："**关掉观测/日志，行为必须完全一致**"（文档 09 §6）。

## 3. 输入模型

- **输入是数据**：每帧输入序列化为 `(frame, input_record)`。
- 模拟**只消费输入记录**，不直接读设备 → 回放时喂同样的记录即可。
- 输入日志随快照一起保存；`replay = 初始快照 + seed + 输入日志`。

## 4. 快照（Snapshot）

- **语义**：完整世界状态的**可序列化副本**（文档 08 的二进制 codec 跑反射描述）。
- **性能优先**（这是与普通保存的区别）：
  - POD 区域直接 **`memcpy`** 到 arena；
  - **脏页 / 增量**快照：只存变更块（copy-on-write）；
  - 预分配快照池，避免运行期抖动（文档 07 §8）。
- **用途**：回滚（rollback）、崩溃复现、AI undo、存/读档、**热重载状态迁移**（文档 02 §6）、编辑器预览。

## 5. 回放（Replay）与失步检测

```
replay = 初始快照 + RNG seed + 输入日志
```

- **每帧状态校验和（checksum）**：回放与原始跑对比，一致则确定。
- **失步（desync）检测**：checksum 不符即报错，并给出**首个分歧帧**。
- **分歧定位**：以检查点（周期性快照）做二分，快速缩小到出错帧与系统。

## 6. 确定性的平台范围（需明确）

**跨平台逐位一致极难**（浮点、libm、SIMD 差异）。务实分层：

| 级别 | 范围 | 可行性 |
|------|------|--------|
| L1 | **同构建同平台**内确定 | 易，默认保证 |
| L2 | **同平台跨构建**（优化等级不同）确定 | 需关 `-ffast-math`、控 FP、慎 SIMD，较难 |
| L3 | **跨平台**逐位确定 | 很难，需定 FP 模型/软浮点 |

**WASM 天然偏 L2/L3**（规范定义浮点确定）→ 浏览器侧回放最稳（文档 05 §2）。
建议：**默认保证 L1，向 L2 努力**；L3 作为可选目标，不做硬承诺。

## 7. 与崩溃 / 观测的闭环

- 崩溃时（文档 09 §5）记录：**seed + 帧号 + 输入日志 + 最近快照引用** → 精确重放。
- trace / 指标（文档 09）与 checksum 时间线对齐，可定位"哪一帧、哪个系统"开始漂移。

## 8. 验证与 CI

- CI 跑固定场景回放，比对 **checksum 序列**；任一平台/构建漂移即失败。
- 快照往返测试：`snapshot → restore → snapshot` 必须逐位一致。

## 9. 遗留风险

| 风险 | 处理 |
|------|------|
| 浮点/Libm 漂移 | 关 fast-math；定范围（§6）；WASM 优先 |
| 未初始化/padding 泄漏 | 零初始化 + 按字段序列化 |
| 迭代顺序不稳定 | id 排序；禁指针哈希 |
| worker 污染模拟 | 模拟单线程；worker 只碰非模拟数据 |
| 快照过大/慢 | 增量 + 脏页 + 池化 arena |
| 异步破坏回放 | 帧内无异步；加载隔离（文档 04） |
