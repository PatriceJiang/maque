# 22 · 多视图与 VR（同屏多屏渲染）

> 上游：`docs/13`（渲染）、`docs/12`（场景）、`docs/20`（运行时）。
> 目标：一帧内渲染**多个视图**（VR 左右眼 / 多屏 / 分屏），一次读回。

## 1. 概念

- **View**：目标内的一块**视口** + **平移(pan)** + **眼距(eye)**。
  - `vx,vy,vw,vh`：视口矩形（像素）。
  - `pan`：把该视图内容平移进自己的视口。
  - `eye`：视差偏移（VR 立体 / 双眼）。
- 一帧 = 目标纹理上按 views 依次渲染；每个视图用**独立 uniform** + **scissor** 限定区域。

## 2. 渲染管线（gfx）

```
render_views(dev, TW, TH, views[], n, sprites[], count, bg, out)
  ├─ 清屏（整目标一次）
  └─ for each view:
        uniform = {TW, TH, pan, eye}
        scissor  = view 视口
        ├─ 实心精灵 pass (load)
        └─ 每纹理组 pass (load)
  → 读回 TW×TH
```

- 顶点着色器：`screen_x = world_x + pan + eye` → 立体视差与多屏平铺**同一套**逻辑。
- `render_offscreen` 即 `render_views` 的单视图包装（向后兼容）。

## 3. 运行时接线

场景字段（`scn.Scene`）：
- `views`：同屏视图数（默认 1；VR = 2）。
- `eye_sep`：眼距/视差（像素）。

运行时据 `views` 生成 View 列表：
```
target_w = W * views
view[i] = { vx=i*W, w=W, h=H, pan=i*W, eye=(i-(views-1)/2)*eye_sep }
```
每帧 `render_views` 渲染，输出 `target_w × H` 图像。

## 4. 实测

`scenes/ball.scn`（`views:2, eye_sep:10`）：
```
runtime: 2 views, eye_sep=10 (VR/多屏)
image size: 640 240
left ball cx=153.3 ; right(相对) cx=163.3 ; parallax=10.00px
```
→ 双眼视差 = `eye_sep`，左右眼图像并排。

## 5. 扩展方向（真正的 VR）

1. **相机/投影**：当前为 2D 屏幕空间；3D/VR 需引入相机与**每眼 view/projection 矩阵**（docs/13 相机、docs/12 分层）。
2. **每眼独立目标**：VR 通常左右眼各自一张纹理（+ 各自 readback/交换），而非并排一张；`render_views` 已按视口组织，扩展为“每视图一目标”很直接。
3. **姿态/头部追踪**：SDLX 可接 OpenXR；eye 偏移替换为头姿 + IPD 向量。
4. **畸变/时间扭曲**：VR 后处理 pass（docs/13 T1 pass 层）。
5. **多屏**：`views` 亦可用于分屏多人 / 多显示器输出。
