# 08 · 资源、持久化与资产管线

> 上游：`06`（反射中枢 = canonical IR）、`04`（VFS 为 IO 底座）、ADR-0011（序列化中枢）。
> 核心诉求：**开发期资源保持文本可读性，方便 git diff 与 AI 理解**；运行/发布用二进制。

## 1. 定位

- **持久化 = 序列化中枢**：唯一内存表示（反射） + 可插拔 `codec × backend`（ADR-0011）。
- **资源（Asset）** = 被引用的数据单元：场景、纹理、网格、材质、脚本、音频…
- **开发期真相是文本，发布期真相是二进制**（同一模型的两种 codec）。

## 2. 序列化中枢：codec × backend（正交）

```
serialize(data, codec, backend)

codec  : text/json · text/yaml · text/toml · binary · binary+compress
backend: vfs path（file:// / zip:// / https:// / mem:// …，由文档 04 提供）
```

- codec 只决定**字节表示**；backend 只决定**落在哪里**。两者正交，任意组合。
- 所有 codec 都是对**反射描述符**的 **visitor**（文档 06 §5）→ 天然覆盖所有类型。

## 3. 双形态、一模型

| 形态 | 用途 | 位置 |
|------|------|------|
| **源文本 (dev source)** | 开发、git、AI、评审 | 入库（tracked in VCS） |
| **烘焙二进制 (cooked)** | 运行、发布、加载 | 派生产物（可 gitignore） |

- 两者由**同一反射模型**派生 → **保证无损往返**（binary ⇄ text）。
- 硬约束：**文本是开发期唯一真相**；二进制是**可再生的缓存/产物**，不得成为唯一真相。

## 4. 文本格式：diff 与 AI 友好规范

> 目标：小的 diff、少冲突、AI 一眼看懂。

- **稳定键序**：字段按 schema 声明序输出，**不按哈希序**（与确定性一致）。
- **数组一行一元素**：减少行内 diff 冲突。
- **省略默认值**：等于 schema 默认值的字段**不写出**（依赖文档 06 的 `default`）→ 噪声最小。
- **稳定 ID / 路径**：引用用稳定 ID 或路径，**禁止**用顺序号（增删即漂移）。
- **禁止易变字段**：时间戳、生成 uuid、绝对路径**不入库**（或走单独元数据）。
- **浮点稳定表示**：统一格式化（如最短往返表示），避免无意义 diff。
- **主推 JSON**（AI 最易解析）+ 可选 YAML/TOML；格式由 codec 决定，模型不变。

## 5. 资产身份与引用

- 每个资产有**稳定 ID**（路径或命名 ID），**不依赖文件顺序**。
- `asset_ref<T>`（文档 07 §6）序列化为**稳定 ID / 路径**；加载时解析并建立引用计数。
- 引用可形成依赖图（§6 用它做增量烘焙）。

## 6. 资产管线（`ai` 模块）

独立、可脱离引擎运行（ADR-0009），支持 AI/CI 驱动：

```
导入 (import) → 依赖图 (deps) → 烘焙 (cook: 文本→二进制) → 打包 (pack) → 压缩 → dump
```

- **增量**：按依赖图只重烘变更项；以**内容哈希**判定失效。
- **确定**：同一输入 → 同一产物（排序、无时间戳、无环境依赖）→ 产物可复现/可比对。
- **dump**：输出机器可读文本（JSON），供 AI 检查、diff、验证。
- **可独立加载 `.scn`**：不启动运行时即可解析场景资产。

## 7. 资源生命周期（运行时）

- 加载经 **VFS（异步 + 缓存）**（文档 04）。
- `asset_ref` **强引用计数**控制存活；释放即回收（文档 07 §6）。
- **流式加载**：大资源分块；**预取**避免帧内抖动（模拟帧内不阻塞，ADR-0018）。
- **热重载**：开发期监听源文本变更 → 重烘 → **帧边界**替换（与文档 12 §6 对齐）。

## 8. 与确定性 / AI 的关系

- 烘焙确定 + 加载隔离 → 不破坏 A3 回放（文档 10）。
- 文本 dump 让 AI 能**读、改、比对**资源（A1/A2）；`mem://` 让 AI 无副作用造数据。
- 源文本入库 → git diff 成为**天然的可观测性**：谁在何时改了玩家数值一目了然。

## 9. 遗留风险

| 风险 | 处理 |
|------|------|
| 文本/二进制漂移 | 单一模型 + 往返一致性测试 |
| 文本体积/加载慢 | 开发用文本、发布烘二进制；文本仅 dev |
| merge 冲突 | 稳定键序 + 一行一元素 + 省略默认 |
| 烘焙不确定性 | 内容哈希 + 排序 + 禁时间戳 |
| 引用悬垂 | 稳定 ID + 加载期解析校验 |
