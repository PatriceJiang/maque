# 19 · 输入与事件分发系统

> 上游：`04`（VFS/平台无关 IO 思路可参照）、`05`（平台抽象/WASM）、`12`（节点树/层级）、`13`（分层/相机）、
> `14`（脚本回调）、`10`（输入即数据/回放）、`11`（控制平面注入输入）、`components/04`（Control/Button/…）。
> 目标：把鼠标/触摸/键盘/输入法**统一为可分发、可录制、可注入**的事件流，并确定地分发到节点/组件。

## 1. 范围

- **输入采集**：设备原始事件（鼠标、多点触控、键盘、手柄、IME、笔）。
- **统一化**：归一为**指针事件（Pointer Events）**模型 + 键盘/文本事件。
- **命中测试**：UI 层优先 + 3D 世界拾取。
- **分发**：DOM 式**捕获→目标→冒泡**三阶段，可停止/消费。
- **状态**：指针捕获、拖拽、键盘焦点、悬停。
- **接缝**：组件信号（`components/04/08/11`）与脚本回调（`14`）。
- **确定性**：输入**即数据**，可录制/回放/注入（`10`、`11`）。

## 2. 统一指针模型（Pointer Events）

鼠标/触摸/笔**归一化**为统一个 `PointerEvent`，用 `pointer_id` 区分（鼠标恒为 0；每根手指一个 id）：

```yaml
- enum: PointerType { Mouse, Touch, Pen }
- struct: PointerEvent
  fields:
    - { name: pointer_id, type: uint32_t }        # 鼠标=0；触摸每指唯一
    - { name: type,       type: PointerEventType } # Down/Up/Move/Enter/Leave/Cancel/Wheel
    - { name: pointer_type, type: PointerType }
    - { name: screen_pos, type: Vec2 }             # 屏幕坐标
    - { name: delta,      type: Vec2 }             # 相对上一帧位移
    - { name: button,     type: uint32_t }         # 0=左 1=右 2=中
    - { name: pressure,   type: float }            # 压感
    - { name: modifiers,  type: uint32_t }         # Shift/Ctrl/Alt/Meta 位标志
    - { name: scroll,     type: Vec2 }             # Wheel 专用
    - { name: timestamp,  type: uint64_t }         # 采样时间（用于插值，不参与模拟判定）
```

**事件类型**：`PointerDown/Up/Move/Enter/Leave/Cancel/Wheel`、`Click`、`DoubleClick`、
`TouchStart/Move/End/Cancel`（兼容别名）、`KeyDown/KeyUp`、`TextInput`、`FocusIn/FocusOut`、`Drag/Drop`。

## 3. 事件管线

```
设备后端(平台) ──raw──▶ InputSystem ──▶ 排队(帧间缓冲) ──▶ [帧处理点] ──▶ 命中测试 ──▶ 分发
   (docs/05)                              buffer            deterministic       hit-test      capture/target/bubble
```

- **采样与消费分离**：设备事件**随时**入队；**在固定处理点**统一消费（对齐 dt，doc 10）。
- 事件队列按**到达顺序**稳定处理（同帧多事件顺序确定）→ 回放一致。

## 4. 命中测试（Hit Test）

**层优先级**（从高到低）：

1. **模态/弹窗层**（Dialog/Popup）—— 独占输入。
2. **UI 层**（RenderLayer=UI）：按 **z-order + 树深**从后往前，矩形/形状命中；受 `visible`/`mouse_filter` 影响。
3. **3D 世界**：相机射线 → `Collider`/`InputTarget` 拾取（最近命中）。
4. 未命中 → 落到根/全局处理器。

- **UI 命中**：`Control` 提供本地矩形；`Mask` 裁剪区域参与命中（`components/08`）。
- **3D 拾取**：复用 physics 的 raycast（`13`/`15`）。
- `mouse_filter`（加在 `Control`）：

```yaml
- enum: MouseFilter
  values: [Stop, Pass, Ignore]   # Stop=消费且不冒泡; Pass=自身处理后继续冒泡; Ignore=不参与命中
```

## 5. 传播模型（捕获 → 目标 → 冒泡）

对命中的目标节点，沿**节点树路径**分发：

```
根 ──捕获(capture, 自顶向下)──▶ 目标(target) ──冒泡(bubble, 自底向上)──▶ 根
```

- **捕获阶段**：祖先可拦截（如拖拽容器）。
- **目标阶段**：目标自身。
- **冒泡阶段**：向上传递，直到被 `stop_propagation()` 或到根。
- **语义 API**（给组件/脚本）：
  - `stop_propagation()` —— 阻止继续传播
  - `consume()` —— 标记已消费（阻止默认行为，如滚动）
  - `is_handled()`
- **滚动/滚轮**：先给目标，未消费则冒泡到最近的 `ScrollView`（`components/08`）。

## 6. 指针捕获与拖拽

- **指针捕获**：`set_pointer_capture(pointer_id)` —— 按下后，该指针的后续 Move/Up **始终**发给捕获者，
  即使移出边界（解决"拖拽丢目标"）。
- **拖拽**：`Drag` 源声明可拖数据；进入候选 `Drop` 目标时发 `DragEnter/DragOver/DragLeave/Drop`。
- 释放：Up/Cancel 时自动释放捕获。

## 7. 键盘焦点与文本输入

- **焦点**：每实例**至多一个**键盘焦点节点；`Tab` 按**确定顺序**（树深序 + `tab_index`）遍历。
- **文本输入**：焦点为 `EditBox`（`components/11`）时，`TextInput`/IME 事件路由给它；
  **IME 组字中间态**不入 `text`（`components/11 §1`）。
- **快捷键/动作映射**：低层按键 → **InputMap 动作**（如 `jump`），供模拟消费；映射表为**数据**，可配置。

## 8. 交接给组件与脚本

- 组件订阅自己关心的事件（如 `Button` 订阅 Down/Up/Enter/Leave/Click；`Slider` 订阅 Drag；`ScrollView` 订阅 Wheel/Drag）。
- **脚本回调**由反射生成绑定（`14`）：如 `on_pointer_down(ev)`、`on_gui_input(ev)`。
- **信号**：组件把语义事件转成信号（`pressed`、`toggled`、`text_changed`），进一步解耦。

## 9. 确定性（关键）

- **输入即数据**：本帧消费的事件序列（及顺序）是**输入记录**的一部分（doc 10 §3）。
- **回放**：喂同一事件序列 → 相同分发 → 相同结果。
- **采样时间戳**：仅用于**渲染插值**（视觉），**不参与模拟判定**（避免墙钟破坏回放，doc 10 D3）。
- **AI/CI 注入**：经控制平面 `Replay`/`Input` domain 注入事件（doc 11），无需真实设备。
- **命中测试确定性**：按 z-order/树深稳定排序，禁地址依赖。

## 10. 平台与多实例

| 平台 | 输入源 |
|------|--------|
| 原生 | OS 窗口事件 → 归一化 |
| 嵌入式 | 触摸/按键驱动 → 归一化 |
| **WASM** | **浏览器 Pointer/Touch/Keyboard/IME 事件** → 归一化 |

- **多实例**：输入系统为 **instance 所有**（ADR-0014）；每个实例独立命中/焦点/捕获状态。
- 控制平面可**指定 instance_id** 注入事件（doc 11）。

## 11. 相关组件调整

- **`Control`**：新增 `mouse_filter : MouseFilter`（默认 `Stop`，纯展示控件可设 `Ignore`）。
- **新增 `InputTarget` 组件**（非 UI/3D 拾取）：给世界对象声明可被指针命中/拖拽，字段：
  `pickable:bool`、`pick_layer:uint32`、`drag_enabled:bool`、`hover_cursor:enum`。
- `BlockInputEvents`（对照 Cocos，`18 §2`）：由 `Control.mouse_filter=Stop` + 遮罩实现，无需单列。
- 交互控件（`Button/CheckBox/RadioGroup/Slider/EditBox/ScrollView`）统一走本系统的三阶段分发。

## 12. 遗留风险

| 风险 | 处理 |
|------|------|
| 事件顺序不确定 → 回放漂移 | 帧处理点统一消费 + 到达序稳定（§9） |
| 触控/鼠标语义分叉 | 统一 Pointer Events 模型 + 兼容别名 |
| 命中测试性能（大量 UI） | 空间索引 + 层裁剪 + 提前退出 |
| 拖拽丢目标 | 指针捕获（§6） |
| 时间戳破坏确定性 | 时间戳仅用于插值，不入模拟（§9） |
| 多实例串扰 | 输入状态 instance 所有（§10） |
