# 07 · 内存与数据模型

> 上游：`00 §5`（packed POD ⇄ 句柄）、`02 R5`（分配者释放）、ADR-0014（零全局状态）、`12`（bake）。
> 本文定义：**分配器模型、句柄与世代、数据布局、组件存储、引用生命周期、内存预算**。

## 1. 目标

- **cache 友好**、**确定**、**嵌入式可控**的内存模型。
- 所有状态**instance 所有**（ADR-0014），无全局可变状态。
- 热路径**零分配**；分配全部经引擎 allocator（跨 `.so` 安全）。

## 2. 分配器模型

统一 C ABI 的 allocator 接口（文档 02 R5）：

```c
typedef struct mq_allocator {
    uint32_t struct_size;
    void* (*alloc)(void* self, size_t size, size_t align);
    void  (*free)(void* self, void* ptr);
} mq_allocator;
```

**分配类别**（每类独立记账，利于观测与预算）：

| 类别 | 生命周期 | 用途 |
|------|----------|------|
| **frame / scratch** | 每帧重置（arena） | 临时计算、构建绘制描述 |
| **persistent** | 实例存活期 | 世界数据、资源 |
| **pool** | 固定尺寸块 | 节点、实体、句柄槽 |
| **virtual** | 保留大块地址 | 大缓冲、GPU 映射 |

规则：

- **禁用裸 `new`/`malloc`**；热路径只用 arena / pool。
- **分配者释放**：绝不跨 `.so` 释放；需要时**传入 allocator**。
- **确定性分配**：分配行为不得依赖地址；**禁止对指针做哈希/排序**（见 §9）。

## 3. 句柄与世代（Handles）

```
handle = { index : u32, generation : u32 }   // 可加 instance_id
```

- **释放即 `generation++`** → 旧句柄自动失效，**悬垂可检测**。
- 槽表 `index → { generation, payload }` 由 instance 持有。
- **为什么用句柄而非指针**：可序列化、可跨进程/跨 `.so`/跨语言、稳定、确定、可被 AI 引用。

## 4. 数据布局原则

- 类型为 **POD + 固定布局**，`static_assert(sizeof==size)`（schema 强制，文档 06）。
- **热数据 SoA**（ECS），**冷数据 / 结构数据 AoS**（节点树、配置）。
- **序列化数据中禁止隐藏指针 / vtable / 平台相关字段**。
- 明确对齐规则，避免隐式 padding 漂移。

## 5. 组件存储（ECS 与节点树）

- **ECS：archetype（SoA）+ 分块（chunk）**。
  - 同一组件组合的实体聚在一起，迭代 cache 友好。
  - 低基数组件可用 **sparse set** 作补充。
- **节点树**：节点为记录，组件经**句柄**挂载（文档 12）。
- **bake**：节点树 → 选定 archetype 的实体集（单向，文档 12 §4）。
- **实体 id 与句柄同构**：`{index, generation}`。

## 6. 引用与生命周期

- `entity_ref` / `asset_ref<T>` 存**句柄**（文档 06 §3）。
- **弱引用 vs 强引用**：
  - `entity_ref` 默认**弱**（实体可被销毁，世代检测悬垂）。
  - `asset_ref` 可**强**（引用计数，控制资源存活，文档 08）。
- 序列化时句柄转**稳定 ID / 路径**；反序列化重建（文档 06 §3）。

## 7. 字符串与容器

- **Interned string**：稳定、便宜、可比较；用于类型名、路径、标识。
- 运行时容器**自研**（arena-backed `vector`、`map`），**不在 ABI / 序列化中用 `std::`**。
- 文本用 UTF-8。

## 8. 内存预算与裁剪（嵌入式）

- 每类分配**独立计数**（bytes / 峰值 / 失败）→ 暴露给 A2（文档 09）。
- **裁剪开关**：关闭反射元数据、缩小 pool、减少 chunk 大小。
- 启动时**预留（reserve）** 关键缓冲，避免运行期抖动。

## 9. 确定性要求

- **禁止地址依赖**：迭代/哈希按 **id / 句柄** 排序，绝不按指针。
- 分配器行为确定；**禁 ASLR 敏感逻辑**。
- 结合 ADR-0018：默认单线程 ⇒ 分配竞争不存在；用 worker 时确定性责任转移给调用方。
- 这些是 A3（回放）在内存层的落点（文档 10）。

## 10. 与其它系统的接缝

| 系统 | 关系 |
|------|------|
| 反射（06） | 字段**偏移**由 schema 决定；序列化按偏移 visitor |
| 持久化（08） | 句柄 ↔ 稳定 ID 转换；arena 支持零拷贝读 |
| 场景（12） | bake 决定实体布局；节点用 pool |
| 脚本（14） | VM 分配经引擎 allocator；帧内禁隐式 GC（OD-5） |
| 平台（05） | WASM 线性内存；无 OS malloc 依赖 |
| 观测（09） | 内存计数器即 perf 指标 |

## 11. 遗留风险

| 风险 | 处理 |
|------|------|
| 跨 `.so` 分配/释放 | R5：分配者释放或传 allocator |
| 悬垂句柄 | generation 校验；调试期加断言 |
| 内存碎片 | pool + arena，避免通用堆长跑 |
| 误用 `std::` | 约定 + 评审；ABI 头不含 `std::` |
| 指针导致的不确定 | 全链路 id 排序；CI 加回放一致性测试 |
