## 生成 / 运行

```bash
# 从 Khronos 源资产重新生成（仓库根目录；源资产需先解包到 .deps/gltf-assets）
python tools/migrate_gltf_models.py --only MetalRoughSpheresNoTextures --force
# 或单独导入：
python tools/gltf_import.py .deps/gltf-assets/glTF-Sample-Assets-main/Models/MetalRoughSpheresNoTextures/glTF/MetalRoughSpheresNoTextures.gltf --out scenes/khronos/MetalRoughSpheresNoTextures --name MetalRoughSpheresNoTextures --scene --compact
# 运行 / 截图
./build-win/samples/player/maque_player scenes/khronos/MetalRoughSpheresNoTextures/MetalRoughSpheresNoTextures.scn
./build-win/samples/player/maque_player --shot /tmp/MetalRoughSpheresNoTextures.png scenes/khronos/MetalRoughSpheresNoTextures/MetalRoughSpheresNoTextures.scn
```
