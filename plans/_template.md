## 2. 接口层设计（完备，先冻结）

> 跨模块接口一律 **C ABI + 版本化 vtable**（docs/02）。接口不完备不得进入实现。

- **公共头**（示意）：
  ```c
  /* mq_<module>.h —— 纯 C */
  #define MQ_<MODULE>_ABI_VERSION 1
  typedef struct mq_<module>_v1 {
      uint32_t struct_size;
      uint32_t abi_version;
      /* 函数指针：完整的操作面 */
  } mq_<module>_v1;
  ```
- **类型**：列出所有公开类型（POD / 句柄）。
- **操作面**：列出**全部**函数及其语义、参数、返回、错误。
- **错误模型**：错误码 / `std::expected` 风格；无异常越界。
- **版本化**：`struct_size` + `abi_version` 前向兼容规则。
- **内存所有权**：分配者释放；传入 allocator 的约定。
- **线程/确定性**：可否跨线程；对模拟帧的影响。

## 5. 开发计划（分阶段 TDD）

1. **阶段 0**：冻结接口头 + 版本号。
2. **阶段 1**：写测试骨架（红）。
3. **阶段 2**：最小实现到绿。
4. **阶段 3**：补边界/错误/确定性用例；重构。
5. **阶段 4**：对接上游 fake 集成；性能/内存达标。

## 6. 验收标准（DoD）

- 接口冻结且被上游 fake 依赖通过；
- 单测覆盖率 ≥ 目标（建议 ≥ 80%）；
- 确定性用例通过（若适用）；
- 性能 / 内存预算达标；
- 无跨模块实现依赖；无全局可变状态。
